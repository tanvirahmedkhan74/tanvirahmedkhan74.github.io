PNEUMA — Perceptual Noesis for Episodic Universal Memory Architecture

How can one moment in a long video remain accessible through several retrieval paths?

Completed undergraduate thesis · Four-person team · December 2025

On this page

  • What we built
  • What happened
  • What it led to

What we built

PNEUMA was our four-person undergraduate thesis at North South University, supervised by Dr. Nabeel Mohammed and completed in December 2025. I was the team lead.

The idea began with an example from Dr. Nabeel Mohammed, while we were looking to human memory for an analogy. A person eating an apple can be remembered as someone eating a fruit, or an apple in particular; as hunger, or a craving for fruit; as a round shape; as the place, the crunch, a related moment from before, or what the person was thinking about and did just after. This is how I read his example:

A memory is never a single event, rather fragmented throughout infinite possibilities of interpretation and observations, consolidating as a whole what the perceptual visualization and interpretation could be, varying with context of why, when and how we retrieve it.

So we wanted one moment in a long video to stay reachable through each of these paths instead of a single flattened embedding.

The system cut a video into overlapping three-second chunks. In each chunk, a V-JEPA model’s attention scores chose the key frames and the same model classified the action; a vision-language model then described the scene, objects, hands and layout, and the audio was transcribed. These descriptions were stored in a hierarchical memory with three parts: SQL records, vector indices for separate aspects, and a temporal graph organised from chunks up to days, weeks and months. A query was answered by combining structured lookup, vector retrieval and temporal relations. No model was trained; this was an integration and memory system built around upstream models.

What happened

The architecture was ambitious. On a 430-question NextQA subset it reached 72.8% zero-shot accuracy, scored by an LLM judge, and its temporal graph reached 98% recall on BETWEEN queries. We did not continue the direction after the thesis.

What it led to

The experience changed what I look for. I became less interested in whether a system can show an apparently intelligent behaviour, and more interested in which components and representations actually make that behaviour possible.

Which stored item supplied the evidence? Which one only helped us reach it? Which apparent capability came from an upstream model? These are the questions I now study in ERL.
