PNEUMA — Video memory for long-form question answering

How can one moment in a long video remain accessible through several retrieval paths?

Completed undergraduate thesis · Four-person team · December 2025

On this page

  • Thesis & contribution
  • Memory architecture
  • Scope & next questions

Thesis and contribution

PNEUMA was our four-person undergraduate thesis at North South University, supervised by Dr. Nabeel Mohammed. I carried out the core technical implementation over six months; teammates helped develop the real-time JavaScript application.

We investigated how video could be searched through actions, objects, places, audio and temporal relationships, using pretrained perception and language models.

Memory architecture

The system organizes model descriptions in SQL records, multi-aspect vector indices and a temporal graph. Query processing combines structured lookup, vector retrieval and temporal relationships to find relevant observations. This is an integration and memory system built around upstream pretrained models.

Scope and next questions

The completed thesis includes an evaluation framework and draft evaluations. The draft runs are not reported as findings here: their scoring provenance is unresolved, and retrieval consistency, persistence and visual grounding remain open before any claim about answer quality. Subsequent ideas about learned forgetting and memory reconstruction are research proposals beyond the completed thesis.

Building this system sharpened my interest in the evidence that survives a pipeline and the evidence an answer actually uses, questions I now study in ERL.
