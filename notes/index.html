Partial observation · December 2025

The geometry of apparent chaos

When a physical system appears to bifurcate unpredictably, the randomness may belong to the observation rather than the full dynamics. A low-dimensional trace can look discontinuous even when its higher-dimensional source is smooth.

What we call noise may sometimes be geometry in coordinates we have not learned to observe.

I wrote a speculative formulation using latent manifolds, Koopman structure, and conditional flow matching to make the intuition precise enough to criticize. It is a hypothesis-only proposal: implementation, experiments, and validation have not yet been completed. Read the six-page working note (PDF).

Memory · May 2025

One moment, several retrieval paths

A person eating an apple can be recalled as an action, a category, a color, a shape, a place, or a neighboring event. That observation motivated PNEUMA's multi-aspect memory: one experience should remain addressable through several attributes rather than a single flattened representation.

The engineering audit later changed the question. A system that returns an answer is not necessarily a system whose memory has been evaluated. The more durable problem is how to test which stored item supplied evidence, which item routed access, and which apparent capability came from an upstream model.

Language models · Open question

Must reasoning move one token at a time?

Autoregressive decoding commits locally. An alternative could refine a latent state iteratively, allowing a representation to settle before it is rendered into tokens. The intuition is not itself a contribution; related work already explores diffusion and continuous latent reasoning. Its value here is methodological: search the literature early and keep an attractive hunch easy to discard.

Practice

Understanding the substrate by rebuilding it

Reading an architecture can create recognition without operational understanding. Reimplementing small systems from primitive tensors exposes the hidden assumptions: tensor shapes, normalization, state, numerical error, and the exact point at which an abstraction stops matching the code.
