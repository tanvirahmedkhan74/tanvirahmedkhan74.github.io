Rank, null space and what a linear map throws away

A grid of points, a 2 by 2 matrix, and the question of what can be recovered afterwards, followed by what that has to do with collapsed embeddings.

Published 2026-11-13 · last reviewed 2026-11-13 · about 20 minutes · references

Assumes Vectors in the plane and the matrix-vector product, The idea of a covariance matrix (only needed for the last two sections)

A matrix is a rule that moves every point of the plane somewhere else. Some rules can be run backwards. Others squash the plane onto a line, so that different inputs end up at the same output and the difference between them is gone for good. Rank and the null space are the two numbers and one subspace that say which case you are in.

The note builds this up from a grid of points, through the rank-nullity theorem and the singular value decomposition, and then separates four things that are easy to run together when people talk about collapsed representations: the rank of a linear operator, the rank of a covariance matrix estimated from finitely many samples, complete collapse to a single point, and dimensional collapse onto a few directions.

All numerical examples are small toy cases made for this note and checked by running the arithmetic. None of the figures is a training result.

Start with a grid of points

Draw a grid of dots on graph paper. A 2 by 2 matrix is a rule that tells you where every dot goes. Apply the rule to all of them at once and the grid is stretched, sheared, rotated, or, as in the animation below, squashed flat.

Play animation — A rank-1 map applied to a grid of points. The animation uses the matrix P=A/5P = A/5 with A=(1224)A = \begin{pmatrix}1&2\\2&4\end{pmatrix} from the first worked example below; dividing by 5 only keeps the picture small. Points that lie along a gold line all land on one point of the teal line.

Showing a still frame instead of the animation.

Download GIF

To describe such a rule you only need to say where two arrows go. Let e1=(1,0)e_1 = (1,0) be the arrow one step to the right and e2=(0,1)e_2 = (0,1) the arrow one step up. A matrix MM is a table of numbers whose first column is where e1e_1 lands and whose second column is where e2e_2 lands. Every other point follows, because (x,y)(x,y) is just xx steps of e1e_1 plus yy steps of e2e_2.

Take S=(2101)S = \begin{pmatrix}2&1\\0&1\end{pmatrix}. Its columns say Se1=(2,0)S e_1 = (2,0) and Se2=(1,1)S e_2 = (1,1). So the point (3,2)(3,2) goes to 3(2,0)+2(1,1)=(8,2)3\,(2,0) + 2\,(1,1) = (8,2). The unit square becomes a slanted parallelogram, and its area is multiplied by det⁡S=2\det S = 2. Nothing was lost: the rule S−1=(1/2−1/201)S^{-1} = \begin{pmatrix}1/2&-1/2\\0&1\end{pmatrix} sends (8,2)(8,2) back to (3,2)(3,2).

Now compare with the map in the animation. Its two columns, (1,2)(1,2) and (2,4)(2,4), point the same way, so the whole plane is built from one arrow and can only reach a line. That is the difference this note is about.

Three kinds of map

It helps to separate three behaviours, because the word compression is used for more than one of them.

  • Invertible. Different inputs always give different outputs, and the whole plane is reached. The matrix SS above is of this kind. Its determinant is not zero.
  • Squeezing but still invertible. The map shrinks some direction hard but not to nothing. For D=(1000.1)D = \begin{pmatrix}1&0\\0&0.1\end{pmatrix} the second coordinate is cut to a tenth, yet D−1=(10010)D^{-1} = \begin{pmatrix}1&0\\0&10\end{pmatrix} restores it exactly. In exact arithmetic nothing is lost; the practical cost is covered in the section on conditioning.
  • Rank-deficient. Some direction is sent to exactly zero. The plane is flattened onto a line (or a point), and no rule can undo it, because the information about that direction is not in the output at all.

Two inputs, one output

Worked example

Let A=(1224)A = \begin{pmatrix}1&2\\2&4\end{pmatrix}. The second row is twice the first, and the second column is twice the first.

  1. Take p=(1,1)p = (1,1). Then Ap=(1⋅1+2⋅1,2⋅1+4⋅1)=(3,6)Ap = (1\cdot1 + 2\cdot1,\ 2\cdot1 + 4\cdot1) = (3,6).
  2. Take q=(3,0)q = (3,0). Then Aq=(3,6)Aq = (3,\ 6). Different input, same output.
  3. Subtract: v=q−p=(2,−1)v = q - p = (2,-1) is a nonzero vector, and Av=(1⋅2+2⋅(−1),2⋅2+4⋅(−1))=(0,0)Av = (1\cdot2 + 2\cdot(-1),\ 2\cdot2 + 4\cdot(-1)) = (0,0).
  4. In general A(x,y)=(x+2y)(1,2)A(x,y) = (x + 2y)\,(1,2). Every point with the same value c=x+2yc = x + 2y lands on c(1,2)c\,(1,2). The input points (1,1)(1,1) and (3,0)(3,0) both have c=3c = 3, so both land on (3,6)(3,6).

The output only reports cc. Everything about where along the line x+2y=cx + 2y = c the input sat is gone.

The step to notice is the third one. If two different inputs collide, their difference is sent to zero; and conversely, if some nonzero vv has Av=0Av = 0, then every input xx collides with x+vx + v, because A(x+v)=Ax+Av=AxA(x+v) = Ax + Av = Ax. A nonzero vector sent to zero and a pair of colliding inputs are the same fact seen from two sides.

Null space, rank and the rank-nullity theorem

Definition

For an m×nm \times n matrix AA (it takes vectors with nn entries to vectors with mm entries):

  • The null space (or kernel) is ker⁡A={x:Ax=0}\ker A = \{x : Ax = 0\}. It always contains 00; it is a line, a plane or a larger flat subspace through the origin.
  • The column space (or image) is the set of all outputs AxAx. It is spanned by the columns of AA.
  • The rank is the dimension of the column space, that is, the number of independent directions the outputs can actually use.

The two sizes are tied together by the rank-nullity theorem (see Strang, Introduction to Linear Algebra, 5th ed., Chapter 3, and Golub and Van Loan, Matrix Computations, 4th ed., Chapter 2):

rank⁡(A)+dim⁡ker⁡(A)=n\operatorname{rank}(A) + \dim \ker(A) = n

Read it as a budget. The input space has nn independent directions. Each one either survives into the output (and is counted by the rank) or is annihilated (and is counted by the null space). Nothing else can happen. For our 2×22\times 2 matrix AA the budget is 1+1=21 + 1 = 2.

Worked example

A 3×33\times 3 case. Let B=(123246101)B = \begin{pmatrix}1&2&3\\2&4&6\\1&0&1\end{pmatrix}.

  1. Row 2 is twice row 1, and row 3 is not a multiple of row 1, so the rank is 2.
  2. Look at the columns: (3,6,1)=(1,2,1)+(2,4,0)(3,6,1) = (1,2,1) + (2,4,0). The third column is the sum of the first two, so B(1,1,−1)⊤=(1,2,1)+(2,4,0)−(3,6,1)=(0,0,0)B\,(1,1,-1)^\top = (1,2,1) + (2,4,0) - (3,6,1) = (0,0,0). The vector (1,1,−1)(1,1,-1) is a null vector.
  3. Rank-nullity then forces dim⁡ker⁡B=3−2=1\dim\ker B = 3 - 2 = 1, so the null space is exactly the line through (1,1,−1)(1,1,-1).
  4. Collisions: Be1=(1,2,1)B e_1 = (1,2,1) and B(2,1,−1)⊤=(2+2−3,4+4−6,2+0−1)=(1,2,1)B\,(2,1,-1)^\top = (2+2-3,\ 4+4-6,\ 2+0-1) = (1,2,1). The inputs (1,0,0)(1,0,0) and (2,1,−1)(2,1,-1) differ by (1,1,−1)(1,1,-1) and cannot be told apart from the output.
  5. The outputs fill the plane y=2xy = 2x in 3-space. For example (1,2,2)(1,2,2) is reachable, but (1,0,0)(1,0,0) is not: its distance from that plane is 2/5≈0.8942/\sqrt5 \approx 0.894.

Two small remarks that prevent common confusion. First, what matters for losing information about the input is the rank compared with nn, the number of input directions. A 3×23\times 2 matrix can have rank 2, in which case its null space is {0}\{0\} and it loses nothing even though its output lives in 3 dimensions. A 2×32\times 3 matrix, in contrast, must have a null space of dimension at least 1. Second, the rank equals the number of nonzero singular values, which is the view developed in the singular value section below.

What can be recovered

Suppose someone hands you y=Axy = Ax and asks for xx. Exact linear algebra gives a clean answer.

  • If ker⁡A={0}\ker A = \{0\} (rank equals nn), then AA is one-to-one on its image. There is a left inverse LL with LA=ILA = I, and x=Lyx = Ly is recovered exactly. For a square matrix this is the ordinary inverse, available exactly when the determinant is not zero.
  • If ker⁡A≠{0}\ker A \neq \{0\}, the best you can say is that xx lies on the flat set x0+ker⁡Ax_0 + \ker A, where x0x_0 is any one solution. Every point of that set gives the identical output, so no method, however clever, can choose among them using yy alone.

So an invertible linear map preserves recoverability in exact arithmetic, and a map with a nontrivial null space destroys it irreversibly. This statement is about the map. It says nothing yet about whether the recovery is practical on a computer, which is a separate question.

Caution

Losing information through a null space and losing accuracy through bad conditioning are different failures. The first is exact and permanent: the output does not contain the information. The second leaves the information in the output but makes it fragile. Do not call a badly conditioned matrix rank-deficient; its rank is full.

A separate issue: conditioning and finite precision

Take the matrix C=(1111+ε)C = \begin{pmatrix}1&1\\1&1+\varepsilon\end{pmatrix} with ε=10−8\varepsilon = 10^{-8}. Its determinant is ε\varepsilon, which is not zero, so CC is exactly invertible and its rank is 2. In exact arithmetic every xx is recovered from y=Cxy = Cx.

The trouble is sensitivity. The condition number κ(C)=σmax/σmin\kappa(C) = \sigma_{\max}/\sigma_{\min}, the ratio of the largest to the smallest singular value (defined in the next section), measures how much an error in yy can be magnified in the recovered xx (Trefethen and Bau, Numerical Linear Algebra, Lecture 12). Here κ(C)≈4.0×108\kappa(C) \approx 4.0\times 10^{8}. Concretely, take x=(1,1)x = (1,1), so y=(2,2+10−8)y = (2,\ 2 + 10^{-8}). Change the first entry of yy by 10−810^{-8}, an error far below anything a measurement or a 32-bit float resolves, and solving Cx′=y′Cx' = y' gives x′=(2,0)x' = (2,0). A relative error of about 3.5×10−93.5\times 10^{-9} in the output became an error of size one in the input.

Finite precision adds a second effect. In 64-bit floating point, 1+10−171 + 10^{-17} rounds to exactly 11, so a matrix that was meant to have ε=10−17\varepsilon = 10^{-17} is stored as (1111)\begin{pmatrix}1&1\\1&1\end{pmatrix}, which is genuinely rank 1. Whether a computed rank is trustworthy therefore depends on a tolerance, and software such as NumPy's matrix_rank counts singular values above a threshold rather than testing for exact zero.

The rule of thumb: rank-deficiency is a statement about the exact map. Ill-conditioning is a statement about how far the exact map is from one that is rank-deficient, together with how much noise you have. A small singular value is a warning, not a null space.

The singular value view

Every matrix, however it looks, acts in three plain steps: turn the input, stretch each axis by its own amount, then turn the result. This is the singular value decomposition (SVD; Golub and Van Loan, Matrix Computations, 4th ed., Section 2.4; Trefethen and Bau, Lecture 4):

A=UΣV⊤A = U \Sigma V^\top

Here VV and UU are orthogonal matrices (rotations or reflections), and Σ\Sigma is diagonal with entries σ1≥σ2≥…≥0\sigma_1 \ge \sigma_2 \ge \dots \ge 0, the singular values. The columns viv_i of VV are input directions, the columns uiu_i of UU are output directions, and Avi=σiuiA v_i = \sigma_i u_i. A direction with σi=0\sigma_i = 0 is annihilated; a direction with σi>0\sigma_i > 0 is stretched by exactly σi\sigma_i.

Worked example

Take M=(3045)M = \begin{pmatrix}3&0\\4&5\end{pmatrix}, which is invertible with det⁡M=15\det M = 15.

  1. Compute M⊤M=(25202025)M^\top M = \begin{pmatrix}25&20\\20&25\end{pmatrix}. Its eigenvectors are (1,1)/2(1,1)/\sqrt2 with eigenvalue 4545 and (1,−1)/2(1,-1)/\sqrt2 with eigenvalue 55.
  2. The singular values are the square roots: σ1=45=35≈6.708\sigma_1 = \sqrt{45} = 3\sqrt5 \approx 6.708 and σ2=5≈2.236\sigma_2 = \sqrt5 \approx 2.236. Check: σ1σ2=15=|det⁡M|\sigma_1\sigma_2 = 15 = |\det M|.
  3. Direction check: M(1,1)=(3,9)M(1,1) = (3,9) has length 90\sqrt{90}, and dividing the input by 2\sqrt2 gives length 45\sqrt{45}. Likewise M(1,−1)=(3,−1)M(1,-1) = (3,-1) has length 10\sqrt{10}, giving 5\sqrt5 after dividing by 2\sqrt2.
  4. The condition number is σ1/σ2=3\sigma_1/\sigma_2 = 3. The map stretches one direction three times as much as the other, and annihilates nothing.

For the rank-1 matrix AA from earlier the singular values are 55 and 00. The map is A=5u1v1⊤A = 5\,u_1 v_1^\top with u1=v1=(1,2)/5u_1 = v_1 = (1,2)/\sqrt5: it keeps only the direction (1,2)(1,2) and annihilates v2=(2,−1)/5v_2 = (2,-1)/\sqrt5, which spans the null space.

So the spectrum σ1≥σ2≥…\sigma_1 \ge \sigma_2 \ge \dots summarises everything this note has described. The rank is the number of nonzero σi\sigma_i. The condition number is σ1\sigma_1 over the smallest nonzero singular value. The input directions with σi=0\sigma_i = 0 span the null space. A second, practical fact is the Eckart-Young theorem (Golub and Van Loan, Section 2.4): the best rank-kk approximation to AA in the spectral norm is obtained by keeping the top kk singular triples, and the error is σk+1\sigma_{k+1}. For MM above, the best rank-1 approximation misses by exactly σ2=5\sigma_2 = \sqrt5.

Connecting to learned representations

In self-supervised and contrastive learning, an encoder maps each input to an embedding vector, and the word collapse describes embeddings that stop using the space available to them. The word covers several different things. Mixing them up is the commonest source of confusion, so they are separated here.

Four meanings that get blurred. Only the first is a property of a linear operator; the rest describe data or an embedding set.
TermWhat it is a property ofHow it is measuredTypical statement
(a) Algebraic rankA linear operator AA (for a network: the Jacobian of the encoder at a point, which is linear)Number of nonzero singular values of the matrixInputs differing along the null space are indistinguishable by this map.
(b) Empirical rankA matrix of nn embeddings of dimension dd, or its covariance estimated from those samplesNumerical rank of the n×dn \times d matrix or the d×dd\times d covariance, given a toleranceCannot exceed min⁡(n,d)\min(n, d), and for a centred covariance it cannot exceed n−1n-1.
(c) Complete collapseThe embedding setAll embeddings equal, so the covariance is the zero matrix (rank 0)The encoder outputs a constant.
(d) Dimensional (partial) collapseThe embedding setA spectrum concentrated in few directions; many singular values near zeroEmbeddings span a low-dimensional subspace of the available space.

(a) Operator versus data. A neural encoder is nonlinear, so it has no single rank. What can be said exactly is that its Jacobian at a given input is a matrix, and that matrix has a rank and a null space in precisely the sense used above. The rank of the matrix of embeddings is a different object: it is a statement about the specific set of points, not about the function that produced them.

(b) Empirical rank depends on the sample. Estimate a 5×55\times5 covariance from only three centred samples and the rank is at most 22, however the data were generated, because three points span at most a 2-dimensional affine plane. A synthetic check with Gaussian noise confirms rank 2 for three samples and rank 5 for a thousand. Empirical rank is therefore never evidence of collapse on its own: you need to know nn, dd, and the tolerance.

(c) Complete collapse. If every input is mapped to the same embedding, then the covariance matrix of the embeddings is zero and its rank is zero. This trivial constant solution is a minimiser of some naive objectives, which is why methods without negative pairs need an explicit guard against it: Chen and He (SimSiam, arXiv:2011.10566) study how a stop-gradient operation lets a Siamese network avoid collapsing solutions, and Bardes, Ponce and LeCun (VICReg, arXiv:2105.04906) add an explicit variance term and a covariance term to the objective for the same purpose.

(d) Dimensional collapse. Here the embeddings are not constant, but they occupy only a low-dimensional subspace of the dd available dimensions. Jing, Vincent, LeCun and Tian (arXiv:2110.09348, ICLR 2022) describe this failure mode, state that it is distinct from complete collapse, and report that contrastive methods can show it too, and they propose a method, DirectCLR, built on their analysis. What they inspect is the singular value spectrum of the embedding covariance, which is the same object as in the previous section.

The right-hand cloud is worth a second look. Its covariance still has numerical rank 5: every singular value is nonzero and a tolerance-based rank test returns 5. Yet 99 percent of the variance sits in one direction, and the effective rank in the caption is about 1.1. This is why plain rank is a coarse tool for dimensional collapse: a spectrum can be full rank on paper and effectively one-dimensional in practice, and which of the two matters depends on what noise and tolerance the downstream use can accept. That last clause is the conditioning issue again, applied to a data matrix rather than a map.

Two caveats that matter

Caution

Low rank is not automatically a defect. A representation for a task with ten classes might need only a handful of directions, and a good compression of high-dimensional data is by nature low-dimensional. Papyan, Han and Donoho (arXiv:2008.08186, published in PNAS) report that the last-layer features of trained classifiers, in the final phase of training, fall onto a very structured low-dimensional arrangement, in which class means form a simplex equiangular tight frame and within-class variability shrinks. They argue this geometry is associated with desirable properties. Whether any given low-rank embedding is a problem depends on whether the discarded directions carried information the task needed.

High rank does not prove a representation is useful. Independent random noise has full-rank covariance and carries no meaning. A representation can spread variance over all directions and still encode the wrong things. Garrido, Balestriero, Najman and LeCun (RankMe, arXiv:2210.02885, ICML 2023) propose the effective rank of an embedding as a label-free signal of downstream quality, and report that it tracks downstream performance in their experiments. That is an empirical correlation reported in one set of experiments, not a theorem that high rank implies a good representation, and the authors' claim should be read at that level.

The balanced reading is that rank and spectrum are useful diagnostics. A fall to rank zero is a clear failure. A fall to a few dominant directions is a reason to look, especially if the task seems to need more. A flat spectrum is necessary for the representation to use its whole space, never sufficient for it to be good.
